# Student Performence Prediction Model
## Introduction
In this project, we compared multiple machine learning models and their performance in student test score prediction.
## Models
- kNN
- Clustering
- Embedding
- Deep Autoencoder
- Bagging
## Model Performance
![image](https://github.com/user-attachments/assets/22a4e409-02da-40e0-804d-8c723005bf62)

Based on the prediction accuracy, we determined that the mixture model of Deep Autoencoder + Clustering + Embeddding is the best-performing model with 70.4% accuracy among the models we tested.
